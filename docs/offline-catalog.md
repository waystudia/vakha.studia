# Каталог как PWA

Общий каталог можно установить на телефон или планшет для показа без интернета.

1. Открыть общую ссылку `/catalog/<token>` в Safari или Chrome.
2. Нажать «Сохранить для офлайн-показа» и дождаться статуса готовности. Загружаются все фото и видео, а не только просмотренные карточки. Объём и прогресс видны на странице.
3. Нажать «Установить на устройство». На iPhone/iPad: Safari → «Поделиться» → «На экран Домой». На Android: меню Chrome → «Установить приложение».
4. Открыть приложение с иконки. Если его хранилище отделено от браузера и список пуст, вставить общую ссылку на стартовом экране и сохранить каталог внутри приложения.
5. Проверить повторный запуск в авиарежиме, полноэкранный показ, фильтры и видео.

Приложение запускается с `/offline-catalog`. Сохранённые каталоги открываются с `?offline=1`: только просмотр, без выбора услуг, WhatsApp и оформления заказа. Вход администратора не требуется. Ссылки классов `/p/…` не принимаются. Дети, заказы, административные ответы API и авторизационные данные не сохраняются этим механизмом.

Обновление требует интернета и загружает текущий публичный каталог. Запись готовности появляется лишь после всех файлов. При обрыве или нехватке места незавершённая копия удаляется, предыдущая остаётся. Хранятся текущая и одна предыдущая полная версия каждого каталога. При очистке памяти браузером каталог следует сохранить снова.

## Реализация и проверки

`vite.config.ts` генерирует `sw.js` с версионированным приложением и хешированными JS/CSS. Большой CRM ZIP не входит в предварительную загрузку. Рабочий процесс не кеширует административные страницы и страницы классов. Превью сохраняются отдельно в Cache Storage с точными URL; видео обслуживаются локально с поддержкой Range/206 и перемотки.

`npm run check` включает тесты незавершённого обновления, утраты медиа, допустимых ссылок, только публичных офлайн-маршрутов, байтовых диапазонов и отсутствия кнопок заказа в просмотре. Для браузерной проверки нужна production-сборка (`npm run build`, `npm run preview`), поскольку worker генерируется при сборке. Проверка на реальном телефоне/планшете дополняет эмуляцию офлайна в браузере.
